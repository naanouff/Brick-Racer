# Bible de ton — Brick Racer

Cible **16+**. Référence d’intention : humour de **Conker’s Bad Fur Day** (absurde, quatrième mur, trash contrôlé) dans un décor **Lego City** coloré.

Ce n’est **pas** un jeu enfant / family-friendly type licence LEGO officielle.

## Oui

- Quatrième mur, PNJ cyniques, panneaux de ville qui se moquent du joueur.
- Absurde brick : accidents comiques, punchlines courtes, UI un peu méchante.
- Langage cru **dosé** ; violence cartoon sur briques (pas de gore réaliste).
- Contraste assumé : ville pastel saturée + dialogues adults.

## Non

- Contenu illégal, harcèlement ciblant des groupes réels, sexualisation de mineurs.
- Gore hyper-réaliste, torture, extrême gratuit sans gag.
- Parodie qui ferait croire à une licence officielle LEGO / Nintendo.
- Spam de jurons sans setup (le trash doit servir une blague ou un personnage).

## Surfaces de ton

| Surface | Exemple d’intention |
| ------- | ------------------- |
| PNJ city | Commentaires acides quand tu rates un pad de course |
| Garage | Mécano qui juge ton kart |
| Boutique | Vendeur qui vend n’importe quoi avec un sourire louche |
| Course | Annonces / items avec punchline courte |
| UI | Tooltips et titres d’écrans avec clin d’œil |

## Garde-fous process

- Toute voiceline / texte long passe une relecture « 16+ OK / trop loin ».
- Les maquettes hub (city, garage, boutique) valident le ton **avant** intégration client quand un nouvel écran apparaît — canon : [ui-ux.md](ui-ux.md) · [../mocup/](../mocup/).
