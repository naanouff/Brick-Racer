# Brick Racer

Course de karts en 3D, skin briques (non officiel). Clone inspiré de Mario Kart, motorisé par [W3DTS](https://github.com/naanouff/w3dts).

**Brick Racer n’est pas affilié à The LEGO Group ni à Nintendo.** LEGO® et Mario Kart™ sont des marques de leurs détenteurs respectifs.

## Jouer / développer

Compiler et lancer : [docs/build.md](docs/build.md).

```bash
pnpm install
pnpm dev
```
