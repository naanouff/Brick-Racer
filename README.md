# Brick Racer

Course / aventure en univers **full brick** (non officiel) : hub **Lego City** explorabile, custom véhicules et minifig, courses solo et multi jusqu’à 4 joueurs. Ton adulte / trash contrôlé (16+). Motorisé par [W3DTS](https://github.com/naanouff/w3dts).

**Brick Racer n’est pas affilié à The LEGO Group ni à Nintendo.** LEGO® et Mario Kart™ sont des marques de leurs détenteurs respectifs.

## Jouer / développer

Compiler et lancer : [docs/build.md](docs/build.md).

```bash
pnpm install
pnpm dev
```
